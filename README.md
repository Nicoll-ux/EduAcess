# EduAcess

Proyecto académico enfocado en el diseño de un Sistema de Gestión Académica centrado en el estudiante, cumpliendo criterios de accesibilidad WCAG 2.2 AA.

---

Objetivo

Diseñar una interfaz accesible que permita a estudiantes:

- Consultar próximas entregas
- Visualizar cursos
- Revisar detalle de curso
- Enviar actividades
- Gestionar su perfil

---

Roles Considerados

- Estudiante con baja visión
- Usuario que navega con teclado
- Usuario con TDAH (reducción de carga cognitiva)
- Usuario con conexión limitada

---

Accesibilidad Implementada

- Contraste mínimo 4.5:1
- Navegación por teclado
- Focus visible
- Mensajes de error textuales
- Uso de landmarks ARIA
- Jerarquía clara de información

---

Estructura del Repositorio

/wireframes → Prototipos en papel con anotaciones  
/design → Archivos Figma y exportaciones PDF  
/docs → Documentación técnica y decisiones  
/demo → Video explicativo (5–7 minutos)

---

Flujo Principal

Login → Inicio → Mis Cursos → Detalle Curso → Enviar Actividad → Perfil
