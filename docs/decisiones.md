Decisiones de Diseño 

-1. Enfoque centrado en el estudiante
El sistema prioriza próximas entregas en el dashboard para reducir ansiedad y facilitar gestión del tiempo.  
Principio aplicado: Usabilidad (SWEBOK – Software Quality).  
Calidad gestionada: Eficiencia y experiencia de usuario.

-2. Navegación accesible por teclado
Se garantiza orden tab lógico y focus visible en elementos interactivos.  
Principio aplicado: Accesibilidad (WCAG 2.2 AA).  
Calidad gestionada: Inclusión y usabilidad.

-3. Uso de tarjetas en "Mis Cursos"
Se utiliza patrón Card para agrupar información relacionada y mejorar escaneabilidad.  
Principio aplicado: Diseño centrado en el usuario.  
Calidad gestionada: Claridad y mantenibilidad visual.

-4. Formularios accesibles
Los campos incluyen labels asociados y mensajes de error textuales.  
Principio aplicado: Prevención de errores.  
Calidad gestionada: Robustez y accesibilidad.

-5. Sistema de espaciado 8px
Se define sistema de espaciado consistente para mantener coherencia visual.  
Principio aplicado: Consistencia y estándares.  
Calidad gestionada: Mantenibilidad.
