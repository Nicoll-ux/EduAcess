# Guía de Estilos

Paleta de Colores

Color primario: #2D6CDF  
Color secundario: #F4F6F8  
Texto principal: #1A1A1A  
Error: #D64545  

Contraste mínimo: 4.5:1 (WCAG 2.2 AA)

---

Tipografía

Fuente: Inter o Roboto  
Tamaño base: 16px  
Escalable hasta 200% sin romper layout.

---

Sistema de Espaciado

Sistema basado en múltiplos de 8px  
(8px, 16px, 24px, 32px)

Objetivo: consistencia visual y mantenibilidad.

---

Componentes Principales

- Botón primario (con estados: hover, focus, disabled)
- Input con label asociado
- Tarjeta (Card) para cursos
- Navbar lateral accesible
- Breadcrumb semántico

---

Accesibilidad

- Navegación por teclado
- Focus visible
- Mensajes de error textuales
- Uso de landmarks ARIA
